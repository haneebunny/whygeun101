# ROADMAP.md — 모두의 외근 개발 로드맵

> 기준 문서: `모두의외근_로드맵.md`, `모두의외근_PRD.md`, `모두의외근_전략기획서_최종본.md`
> 이 문서는 진행 순서와 현재 상태를 함께 추적하기 위한 것이다. Phase가 끝날 때마다 체크박스와 "현재 상태"를 갱신한다.

---

## 전체 순서

```
Phase 0  PRD + 디자인 탐색(Stitch)          ← 병행, 가장 먼저
Phase 1  규칙·거버넌스 문서 + 에러핸들링 정의   ← 지금 여기
Phase 2  리팩토링 + 새 디자인 적용(헤더·푸터부터)
Phase 3  AX 1순위 — 주소 보정
Phase 4  AX 2순위 — 동선 최적화
Phase 5  필수 부가사항(개인정보처리방침·약관·웹뷰 준비)
```

각 Phase는 이전 Phase의 산출물을 전제로 한다. 순서를 건너뛰지 않는다 (규칙 없이 리팩토링하거나, 리팩토링 없이 AX 기능부터 얹으면 지금까지의 무질서가 반복된다).

## 우선순위 원칙 (전략기획서 5-2 기준)

1. **주소 보정(긴급)** — 잘못된 핀은 헛걸음으로 직결되고, 헛걸음은 신뢰를 무너뜨려 서비스 자체를 안 쓰게 만드는 가장 치명적인 결함이므로 최우선.
2. **동선 최적화(MVP 핵심)** — 이미 보유한 핀 데이터로 추가 데이터 수집 없이 바로 가치를 줄 수 있음.
3. **전화 일정 조율 보조(차순위, 이 로드맵 범위 밖)** — 완전 자동화 리스크가 커서 MVP 이후로 미룸.
